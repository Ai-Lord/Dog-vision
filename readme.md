# 🐶 Dog Vision – Dog Breed Classification using CNN

This project implements a **Dog Breed Classification system** using Deep Learning. A Convolutional Neural Network (CNN) with **MobileNetV2 transfer learning** is used to predict the breed of a dog from an input image. The project was developed and executed in **Google Colab**.

## 🚀 Features

- Dog breed classification using CNN
- Transfer learning with MobileNetV2
- Custom image prediction
- Top-5 prediction visualization
- TensorFlow & Keras based implementation

## Dataset Used

The data we're using is from Kaggle's dog breed identification competition. https://www.kaggle.com/competitions/dog-breed-identification/data
